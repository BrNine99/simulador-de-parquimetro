# 🅿️ Simulador de Parquímetro

## 📌 Sobre o projeto

Simulador de parquímetro desenvolvido com HTML e JavaScript para praticar conceitos de **Programação Orientada a Objetos (POO)**.

O sistema recebe um valor, calcula o tempo de estacionamento disponível e informa o troco, caso exista.

## 🚀 Funcionalidades

- Cálculo do tempo de estacionamento.
- Cálculo automático do troco.
- Validação do valor informado.
- Exibição dos resultados na página.

## 💰 Tabela de tarifas

| Valor | Tempo |
|---|---|
| R$ 1,00 | 30 minutos |
| R$ 1,75 | 60 minutos |
| R$ 3,00 | 120 minutos |

O tempo máximo de estacionamento é de 120 minutos.

## 🛠️ Tecnologias utilizadas

- HTML5
- JavaScript
- CSS (arquivo referenciado no HTML)

## 📚 O que aprendi

Durante o desenvolvimento, pratiquei:

- **POO:** classes, objetos, construtores e encapsulamento.
- **JavaScript:** arrays, objetos, métodos, condicionais e laços de repetição.
- **DOM:** captura de eventos e atualização de elementos HTML.
- **Validação:** tratamento de erros com `try...catch`.
- **Valores monetários:** cálculos em centavos e formatação com `Intl.NumberFormat()`.

## ▶️ Como executar

1. Baixe ou clone o repositório.
2. Abra o arquivo `index.html` no navegador.
3. Informe um valor e clique em **Calcular estacionamento**.

## 🎯 Objetivo

Aplicar os conhecimentos de JavaScript e POO na construção de uma aplicação simples, praticando lógica de programação, organização do código e manipulação do DOM.
